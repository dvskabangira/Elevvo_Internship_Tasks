Completed tasks in this internship include; 
**(i)** Student score prediction
**(ii)** Customer segmentation
**(iii)** Loan prediction
**(iv)** Traffic sign recognition.

## Task 1: Student score prediction
Description:
- Built a model to predict students' exam scores based on their study hour
- Performed data cleaning and basic visualization to understand the dataset
- Split the dataset into training and testing set
- Trained a linear regression model to estimate final score
- Visualized predictions and evaluate model performance


## Task 2: Customer segmentation
Description:
- Clustered customers into segments based on income and spending score
- Performed scaling and visual exploration of groupings
- Apply K-Means clustering and determined optimal number of clusters
- Visualized clusters using 2D plots


## Task 3: Loan prediction
Description:
- Built a model to predict whether a loan application will be approved
- Handled missing values and encoded categorical features
- Trained a classification model and evaluated its performance on imbalanced data


## Task 4: Traffic sign recognition
Description:
- Classified traffic signs based on their image using deep learning
- Preprocessed images (resizing, normalization)
- Built and  trained a CNN model to recognize different traffic sign classes
-  Evaluated model performance using accuracy and confusion matrix
